## 2026-07-22 - AiOrchestratorService State Machine
**Инсайт:** Имплементация конечного автомата (OrchestratorService) должна строго придерживаться событийно-ориентированного подхода с передачей контекста между состояниями, избегая глухих заглушек. Запрос точных данных из генома и сети в `OrchestratorEvent` гарантирует безопасные переходы.
**Действие:** Использовать `tokio::sync::Mutex` для управления состоянием в асинхронном контексте, а также `enum` для определения событий.
